# input/

Download `Lista-FantaAsta-Fantacalcio.csv` from fantacalcio.it (**App → FantaAsta Live →
Calciatori Serie A**) and place it directly in this folder, so the file is at:

```
data-pipeline/input/Lista-FantaAsta-Fantacalcio.csv
```

Then run `npm run data:build` from the `mantravibe/` root. The CSV itself is gitignored — only
this README is tracked, to keep the folder present after a fresh clone.
